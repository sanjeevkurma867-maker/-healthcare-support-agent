# Prior Authorization Requirements: Extended Physical Therapy
This document lists what an extended physical therapy request must contain. All content is fictional and used for a prototype.

## Requirements
The request must include the member number and the requested service date. It must include a physical therapy evaluation and a treatment plan with goals. It must show the number of visits already used. It must include a referral from a physician.

## When it applies
Prior authorization is needed when the member requires more than 12 physical therapy visits in a plan year.
