# Support Case Escalation Procedure (internal)
This procedure is for support agents only. All content is fictional and used for a prototype.

## When to escalate
Escalate a question to a case when the assistant cannot find supporting evidence, when the member asks for a person, or when a claim needs manual review.

## Response time
Open cases must be picked up within 2 business days. A resolved case needs a short note that says what was done.

## Case statuses
A case moves from open to assigned, then in progress, then resolved. A case can be set to awaiting user when the agent needs more information, or cancelled if the request is withdrawn.

## Internal-only note
Support agents must not share this procedure with members.
