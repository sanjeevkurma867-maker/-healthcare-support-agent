# Prior Authorization Guide for Providers
This guide explains how providers request prior authorization. All content is fictional and used for a prototype.

## Submission
Providers submit a prior authorization request through the provider portal with the member number, the requested service, the requested service date and the ordering provider identifier.

## Required packet
Every request must include the member number, the requested service date, the ordering provider identifier, a referral letter when the service requires one, and clinical notes that support medical necessity.

## Turnaround
Standard requests are decided within 7 business days. Urgent requests are decided within 72 hours.

## Incomplete requests
Requests that are missing a required document are returned as incomplete. A returned request restarts the review clock.

## Readiness checks
A readiness check reviews documentation completeness only. It is not an approval and it is not a denial.
